# Mini Expense Tracker

A simple expense tracker built for a Skill Lab project using HTML, CSS and vanilla JavaScript.

Project Status: UI Completed

## Features

- Add expenses with a title, amount and category
- See the total spending at a glance
- View all expenses in a list
- Delete expenses

## Tech Stack

- HTML
- CSS
- JavaScript
